# ✈️ Flight Delays 2019–2023 – Power BI Dashboard

## 📌 Project Overview

This Power BI project analyzes flight delays, cancellations, airline performance, and monthly flight trends from **2019 to 2023**.

The dashboard provides interactive visualizations to understand flight performance, identify airlines with higher cancellations and delays, analyze routes and airports, and forecast future flight activity.

---

## 🎯 Project Objectives

- Analyze overall flight delays and cancellations
- Compare airline performance across different years
- Identify the **Top 10 airlines by total cancelled flights**
- Analyze average departure and arrival delays
- Analyze flight activity by origin city
- Identify monthly flight trends
- Compare flight performance across years
- Create an interactive drill-through page for detailed flight information
- Use forecasting to analyze future flight trends

---

## 📊 Dashboard Pages

### 1. Overview

Provides a high-level summary of flight performance using key metrics and visualizations.

### 2. Airline Performance

This page includes:

- **Top 10 Airlines by Total Cancelled Flights**
- **Top 10 Airlines by Average Departure Delay**
- **Cancellation Rate by Airline and Year**
- Airline performance comparison
- Conditional formatting for cancellation rates

### 3. Route & Airport Map

Provides a geographical analysis of flight origin cities using a map visual.

### 4. Drill-Through Detail

Provides detailed flight-level information including:

- Flight Date
- Airline Code
- Origin
- Destination
- Arrival Delay
- Departure Delay
- Cancelled Flights

The page also contains summary cards for:

- **Total Flights**
- **Average Departure Delay**
- **Average Arrival Delay**

### 5. Trends & Forecast

This page includes:

- **Monthly Cancellation Rate**
- **Monthly Average Departure Delay**
- **Monthly Average Arrival Delay**
- Monthly flight trends by year
- Forecast of future flight activity
- **6 forecast points**
- **95% confidence interval**

---

## 🧮 DAX Measures

The project uses DAX measures for calculating important flight performance metrics.

### Measures Used

- `Total_Flights`
- `Total_Cancelled`
- `Cancellation_Rate`
- `On_Time_Rate%`
- `Avg_Dep_Delay`
- `Avg_Arr_Delay`

These measures are used throughout the dashboard to calculate KPIs and support different visualizations.
